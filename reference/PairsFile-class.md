# `PairsFile` S4 class

The `PairsFile` class describes a `BiocFile` object, pointing to the
location of pairs file, typically generated by `HiCool::HiCool()`.

PairsFile methods

## Arguments

- x:

  Path to a pairs file

[`CoolFile()`](CoolFile-class.md), [`HicFile()`](HicFile-class.md),
[`HicproFile()`](HicproFile-class.md)
