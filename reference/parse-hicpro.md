# Parsing hicpro files (matrix & bed)

These functions are the workhorse internal functions used to import
HiC-Pro `.matrix` and `.bed` files as GInteractions (wrapped into a
`HiCExperiment` object by [`HiCExperiment()`](HiCExperiment.md)
function).

## Usage

``` r
.hicpro2gi(file, bed)

.getHicproAnchors(bed)

.hicpro2seqinfo(bed)

.dumpHicpro(file, bed)
```

## Arguments

- file:

  path to a matrix file from HiC-Pro

- bed:

  path to the regions file generated by HiC-Pro

## Value

a GInteractions object
